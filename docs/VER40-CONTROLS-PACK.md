# VER40 Controls Pack (WIP)

This branch adds custom touch-control skin assets for the Android build of Ninja Gaiden Black recomp.

- New button art for run/evade, shuriken, sword, ninja, shoulders/triggers and system controls.
- Analog joystick base, center and active ring assets.
- Four-way D-pad and directional arrow artwork.
- Gear icon for the touch-control overlay.

The APK built from this work is a candidate/test build. The complete visual editor settings panel and custom-layout rendering are not finished or runtime-tested. Game files are not included; users must supply legally obtained game data.
